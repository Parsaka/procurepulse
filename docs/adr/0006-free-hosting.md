# 6. Free hosting: a static dashboard on GitHub Pages from aggregates in the repo

**Status:** accepted

**Context.** The demo must be public, always on, and cost nothing; Power BI publish-to-web needs a paid or
organisational tenant.

**Decision.** The public demo is a static page (`site/build.py`) built from the aggregated Parquet files
committed under `app/data` (about 300 KB, regenerated by `make app-data`) and deployed to GitHub Pages by
`.github/workflows/pages.yml`. The interactive Streamlit app reads the same files and runs locally
(`make app`). Streamlit Community Cloud was tried first and dropped: the app hung on load for anonymous
visitors and later disappeared from the account, which is not acceptable for a link on a CV. Power BI is built in Desktop from the exported star schema or from
Snowflake, and shown as screenshots.

**Consequences.** No warehouse, secret or server is needed to view the results, and the page cannot go to
sleep; case-level data stays out of
the public app except the top-decile alert list.

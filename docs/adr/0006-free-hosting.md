# 6. Free hosting: Streamlit Community Cloud from aggregates in the repo

**Status:** accepted

**Context.** The demo must be public, always on, and cost nothing; Power BI publish-to-web needs a paid or
organisational tenant.

**Decision.** The Streamlit app reads only aggregated Parquet files committed under `app/data` (about
300 KB), regenerated by `make app-data`. Power BI is built in Desktop from the exported star schema or from
Snowflake, and shown as screenshots.

**Consequences.** No warehouse, secret or server is needed to view the results; case-level data stays out of
the public app except the top-decile alert list.
